Thẩm Định Giảm Thiểu Dữ Liệu (Client-Side SHA-256 Data Minimization)

Nguyên tắc Giảm thiểu Dữ liệu (Data Minimization): Trình duyệt của bạn sẽ tự tính toán mã băm SHA-256 bằng Web Crypto API trực tiếp trong bộ nhớ máy trạm. Nội dung bytes của tệp không rời khỏi máy trạm; hệ thống chỉ gửi chuỗi hash 64 ký tự và UUID lên máy chủ để tra cứu chữ ký số và trạng thái thu hồi.
